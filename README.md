Deskripsi:
Wedding Needs Store adalah sebuah website berbasis web yang dibuat untuk memenuhi kebutuhan perencanaan pernikahan.
Website ini menyediakan berbagai informasi dan layanan terkait kebutuhan wedding seperti paket pernikahan, dekorasi, pakaian, galeri, serta fitur keranjang dan checkout.  


Daftar Fitur:
- Halaman Beranda (Home)
- Daftar Produk & Paket Wedding
- Paket Promo
- Galeri Foto
- Halaman Tentang
- Halaman Kontak
- Keranjang Belanja (Cart)
- Checkout Produk
- Dark Mode
- Desain Responsif (Desktop & Mobile)


Teknologi yang Digunakan:
- HTML – Struktur halaman website
- CSS – Styling dan layout
- JavaScript – Interaksi dan logika website
- Bootstrap – Komponen UI dan responsivitas
- Git & GitHub – Version control dan repository project
